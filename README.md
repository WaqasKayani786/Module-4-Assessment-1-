# Pine City Zoo 🦁

A responsive zoo website created as part of the **IT Varsity Module 4 – Pine City Zoo** assessment.

## 📖 About the Project

Pine City Zoo is a fictional zoo website that allows visitors to explore the zoo, learn about its animals, and find information about different places and facilities within the zoo.

The website was developed using the web development concepts covered in the IT Varsity course.

## ✨ Features

* 🗺️ Zoo map and navigation
* 🦁 Animal information pages
* 📍 Information about places around the zoo
* 🏞️ Zoo facilities and attractions
* 🔗 Navigation between different sections
* 🎨 Custom styling and images

## 🛠️ Technologies Used

* **HTML** – Structure and content
* **CSS** – Styling, layout and design
* **GitHub Pages** – Website hosting
